# 📘 GitHub for DevOps

## 📌 Overview

This repository is created to learn and practice **Git fundamentals and workflows** used in DevOps. It contains hands-on exercises and examples to understand how Git is used in real-world development and deployment environments.

---

## 🚀 Topics Covered

### 🔹 Git Basics

* `git init` – Initialize a repository
* `git clone` – Clone a remote repository
* `git add` & `git commit` – Track and save changes

---

### 🔹 Git Workflows

* Branching strategies
* Creating and switching branches
* Merging branches

---

### 🔹 Advanced Git

* Rebasing
* Conflict resolution
* Clean commit history

---

## 🛠️ Purpose

* Build a strong foundation in Git
* Understand real DevOps workflows
* Practice version control in a structured way

---

## 📂 Structure

This repository will be updated regularly with:

* Practice commands
* Example workflows
* Notes and learnings
